九、数据真实性处理口径

- 只有接口真实返回、订单预览真实校验、授权账号真实回查的数据，才能在导出中标记为真实数据。
- API 回包没有返回的字段，不用样例数据补齐，不写成真实数据。
- 没有单独接口名的字段，不额外编造接口名；申请时统一作为上面已有接口的字段范围确认，拿到企业账号实际回包后再接入项目字段映射。
- 品退率、发货率、24小时揽收率、好评率、评论数、评价标签、店铺粉丝数、店铺商品数、商家特色、经营模式、是否源头工厂、是否支持微信小店面单，均按真实回包校验；未拿到真实回包前在系统里保持未核验状态。
