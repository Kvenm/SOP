## 继续修改：任务历史持久化（2026-07-20）

### 目标与边界

- 解决 Web 服务或 Windows 计划任务重启后，最近任务状态直接从页面消失的问题。
- 不自动恢复已经被重启打断的 RPA 子进程，不把“中断”伪装成“暂停后会继续”。
- 不保存配置对象、商品明细、Cookie、Token、浏览器 profile 或安全验证链接。
- 不运行真实 1688 采集，不启动采集 Chrome，不提交或推送。

### 实现

- `{TAG_COLLECT_DATA_DIR}/web_tasks.json` 保存最近 20 条安全任务摘要，使用临时文件加 `os.replace` 原子写入。
- 每次任务创建、进入 running、进度更新、取消请求和终态都会刷新摘要。
- 服务加载历史时，终态原样保留；历史 `queued/running/cancelling` 改为 `interrupted`，补齐结束时间和“不会自动继续”原因。
- `/api/options` 返回 `recent_tasks`；页面新增“最近任务”卡片，展示时间、类目/采集方式、页数、候选/结果数量、停止原因和状态。
- 完成任务可通过“查看结果”调用 `/api/run` 重新载入已有本地批次，或直接下载；不会重新访问 1688。
- `interrupted` 使用黄色状态卡，顶部活动进度不会把它当作仍在执行的任务。
